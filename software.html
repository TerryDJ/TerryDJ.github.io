What the Code Supports

Trajectory Processing

Cleaning tracked object data, filtering incomplete tracks, aligning time points, and preparing migration trajectories for downstream analysis.

Quantitative Metrics

Computing displacement, path length, speed, directional persistence, endpoint distance, and condition-level summaries.

Experiment Comparison

Organizing replicate experiments, comparing treatment groups, and generating tabular outputs for statistical analysis.

Visualization

Producing trajectory overlays, scatter plots, summary distributions, and publication-ready figures for migration behavior.
